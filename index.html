在 VS Code 裡讓 Codex 變強：Skills、MCP、Plugins

給第一次用 Codex 擴充功能的同學。圖看懂就好，細節都收在可展開的區塊裡。

01一張圖看懂運作原理

你在 VS Code 的 Codex 面板打字，Codex 靠兩種東西把事做好：讀「說明書」（Skill）、用「工具」（MCP）。Plugin 只是把兩者打包。

02三個概念，各一句話

Skill

教 Codex「怎麼做某件事」的 SOP 手冊。一個資料夾加一份 SKILL.md。

~/.codex/skills/

MCP server

給 Codex「新工具」。像外接一台印表機，讓它能操作 GitHub、資料庫、瀏覽器。

~/.codex/config.toml

Plugin

把 Skill + MCP + 帳號連接「打包」。從 marketplace 一鍵裝，全部到位。

~/.codex/plugins/
口訣 Skill 教它怎麼做 MCP 給它新工具 Plugin 一鍵打包裝

04三條安裝路線

先問自己「我想要什麼」，再走對應那一條。指令可在 VS Code 內建終端機執行（Ctrl + `）。

我想要 Codex 學會一套做法

裝 Skill

  1. 1
    找到 skillGitHub repo 裡一個含 SKILL.md 的資料夾
  2. 2
    裝進去（三選一）在 Codex 對話框：› $skill-installer gh-fix-ci終端機，任意 GitHub repo：$ npx skills add anthropics/skills --skill frontend-design -a codex -g或直接把資料夾複製到 ~/.codex/skills/
  3. 3
    重開 Codex 面板打 /skills 確認有出現
我想要 Codex 能操作外部系統

接 MCP

  1. 1
    拿到啟動指令或 URL例如 context7：npx -y @upstash/context7-mcp
  2. 2
    加進設定（二選一）VS Code：⚙ → MCP servers → Add server終端機：$ codex mcp add context7 -- npx -y @upstash/context7-mcp
  3. 3
    Restart，打 /mcp 確認工具會列出來就是成功
我想要一次全包、不想手動設定

裝 Plugin

  1. 1
    打開 plugin 瀏覽器Codex 對話框：› /plugins
  2. 2
    搜尋、按 Install官方 marketplace 已內建 superpowers、github、notion、figma…終端機也行：$ codex plugin add superpowers@openai-curated
  3. 3
    重開 session需要登入的（Gmail、Slack）會跳出授權

接下來是給 Codex 看的指令、步驟、檢查清單……

資料夾可以再放 scripts/（腳本）、references/（參考文件）、assets/（範本）。想自己做就在對話框打 $skill-creator，它會一步步問你。

要暫時關掉某個 skill，在 config.toml 加：

config.toml
[[skills.config]]
path = "C:/Users/你/.codex/skills/my-skill/SKILL.md"
enabled = false
MCP 完整設定範例（config.toml）與常用指令
config.toml
# 本機程式（stdio）
[mcp_servers.context7]
command = "npx"
args = ["-y", "@upstash/context7-mcp"]
startup_timeout_sec = 10

# 遠端服務（Streamable HTTP）
[mcp_servers.remote]
url = "https://mcp.example.com/mcp"
bearer_token_env_var = "MY_TOKEN"     # 或 auth = "oauth"

# 可選：白名單 / 黑名單 / 核准模式
# enabled_tools = ["read", "search"]
# disabled_tools = ["delete"]
# default_tools_approval_mode = "prompt"   # auto / prompt / writes / approve
terminal
$ codex mcp list                 # 看有哪些、狀態
$ codex mcp add NAME --env K=V -- CMD   # 帶環境變數
$ codex mcp add NAME --url URL   # 遠端
$ codex mcp login NAME           # OAuth
$ codex mcp remove NAME
頂層 key 是 mcp_servers（底線）。Claude 與 Cursor 用的 mcpServers 在這裡無效。專案專用的 MCP 放在 <專案>/.codex/config.toml，專案要先 trusted。
Plugin 命令列與自製 plugin 的資料夾結構
terminal
$ codex plugin marketplace list
$ codex plugin list
$ codex plugin add superpowers@openai-curated
$ codex plugin marketplace add https://github.com/ComposioHQ/composio-plugin-openai.git
$ codex plugin add composio@composio
$ codex plugin marketplace upgrade
$ codex plugin remove NAME

自製 plugin 的最小結構：my-plugin/.codex-plugin/plugin.json（必要），再加 skills/、.mcp.json、.app.json、hooks.json。範例看 openai/plugins。

07常見問題

裝了但 /skills 看不到

重開 Codex 面板或重載 VS Code 視窗。確認資料夾內有 SKILL.md，且 frontmatter 有 name 與 description。

終端機加的 MCP，VS Code 擴充沒出現

兩邊共用 ~/.codex/config.toml，但擴充需要重啟才會重新讀取。⚙ → MCP servers → Restart，或重載 VS Code 視窗。Windows 上 npx 找不到時，command 改成 cmd、args 用 ["/c","npx","-y","..."]。

專案級設定沒生效

專案要先被 trust。第一次開專案時選 trusted，或在 config.toml 的 [projects.'C:\路徑'] 設 trust_level = "trusted"。

Windows 路徑怎麼寫

config.toml 裡用正斜線 C:/Users/... 或雙反斜線。

安全注意

不要把 token 寫進 SKILL.md。MCP token 用 bearer_token_env_var 或 env 讀環境變數。第三方 skill 裝之前先看一眼 SKILL.md 與 scripts/。

同一份 skill 想給 Claude Code 也用

SKILL.md 是通用格式，複製到 ~/.claude/skills/ 即可。或 npx skills add ... -a codex -a claude-code 一次裝兩邊。
